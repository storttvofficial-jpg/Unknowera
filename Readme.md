# Unknowera

Unknowera is an all‑in‑one AI‑powered file manager, code builder, and chat assistant. It allows you to upload and extract files, chat with NVIDIA Nemotron 3.5, generate full apps as ZIP, preview code, execute safe commands, and search the web.

## Features

- Upload ZIP, images, and any files; extract ZIPs client‑side.
- AI chat with NVIDIA Nemotron 3.5 (via NVIDIA API).
- Bilingual (English/Hindi) responses.
- Code blocks with syntax highlighting, copy, preview, and download.
- Full app generation with automatic ZIP packaging.
- Tool use: command execution and web search.
- Thought process visualization.
- Chat history persisted in localStorage.
